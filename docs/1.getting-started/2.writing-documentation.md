# Writing documentation

Every Markdown file below `docs/` becomes a page. Its filename determines the
URL, and an optional numeric prefix determines its position in navigation.

```text
docs/
├── index.md
└── 1.getting-started/
    ├── index.md
    └── 2.writing-documentation.md
```

Use frontmatter to set the title, description, and sidebar icon:

```md
---
title: A page title
description: A short description for readers and search engines.
icon: lucide:file-text
---
```

Create folders when the documentation grows. duxt keeps the numeric prefix out
of the URL, so `docs/1.guides/1.installation.md` is served at
`/guides/installation`.
